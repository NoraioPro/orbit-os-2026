Earth Sound Jukebox

Each column of the grid is one month, each row is a latitude band. The playhead reads the grid left to right. Each row plays a pitch, and each value sets how loud that pitch sounds.

Sample data only. The grid is synthetic and generated in the page. It is labelled as illustrative, not observed Earth data, and is not a NASA Earth Information Center frame.

Next steps to use real data

  • Replace the synthetic grid with real gridded data, such as the NASA GISTEMP surface temperature anomaly product, or a NASA Earthdata product, read in a server or preprocessing step.
  • Use the NASA Earth Information Center's own visualization frames as the visual track, and check their usage terms.
  • Add a sound-mapping key for listeners, and test with students whether they can tell high from low values.
  • Consider a colour-blind-safe palette and a non-audio text description of each frame.
