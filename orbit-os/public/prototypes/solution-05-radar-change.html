Next steps to use real data

  • NISAR L-band products: the NASA-ISRO SAR mission provides geocoded L-band products (for example GCOV and GSLC) through NASA Earthdata. Confirm the current product levels, versions and access rules there before use.
  • Calibration: convert the stack to calibrated backscatter in dB, correct for incidence angle, and apply the product's quality and layover masks.
  • Cross-checks: compare classes against an optical record (Landsat or Harmonized Landsat Sentinel-2) or ESA's Sentinel-1 C-band radar.
  • Ground truth: validate classes against flood extents, fire perimeters, glacier outlines and field records.
  • Location input: replace the four preset sites with a map search and a date range, then load the matching NISAR stack.
Prototype limits: one 48 by 32 cell grid stands in for a scene. No geolocation, terrain correction, polarization choice or cloud-free compositing is modeled.
