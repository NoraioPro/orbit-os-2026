Insights Rule-based SI stand-in

    The "SI" layer in this prototype is a rule-based stand-in: fixed if-then statements and a fixed weighted score applied to the table. It is not a trained model, and a real system would need its output checked against expert review and test data.

    How the risk score works

    Each factor is scaled to 0 to 1 over a fixed range, then weighted. Higher values mean higher risk.

    score = 100 × (0.30·O2 + 0.20·Pressure + 0.30·Spread + 0.20·Extinguish)
    O2 range 18 to 35 %, Pressure 50 to 101 kPa, Spread 0 to 5 mm/s, Extinguish 3 to 20 s

    Next steps to use real data

    • Map each real experiment's recorded fields (fuel, oxygen fraction, pressure, spread rate, extinguishment time, outcome) onto this schema and keep the source and version for every row.
    • Replace the fixed weights with values agreed by fire-safety engineers, and test the ranking against known outcomes.
    • Put a trained model behind the SI layer only after it is validated on held-out experiments, and keep the rule-based view as the auditable baseline.
