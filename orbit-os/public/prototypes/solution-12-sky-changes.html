What is a mover?

Most points of light in the sky stay in the same place from one image to the next, so they are stars or distant galaxies. A mover is a point that changes position between images taken at different times. Comets, asteroids and some distant planets can show up this way. Finding movers means comparing images and checking which points shifted, and by how much.

Use the blink view to watch the motion by eye, the difference view to see what changed, and the detector to list each mover with its direction and speed.

How the detector works

  • Find points brighter than the sensitivity threshold and brighter than their neighbors, in each frame. Each point's position is refined to a fraction of a pixel.
  • Compare the two chosen frames. A point present in both at the same place is a fixed star or galaxy and is ignored.
  • Pair each point that appears only in frame A with a point that appears only in frame B, within the largest motion you allow. Each pair is one mover, and its shift gives direction and speed.
  • This prototype assumes the frames are already lined up. A real pipeline must first align each image to a reference star catalog.

Next steps to use real data

  • Load real SPHEREx sky images and their associated products from NASA's SPHEREx data archive, which is hosted by the NASA/IPAC Infrared Science Archive. Check the product list for the image level you need.
  • Align frames with a star catalog such as ESA's Gaia, using a proper world-coordinate transform rather than assumed alignment.
  • Check candidate movers against known solar system objects, using the Minor Planet Center's published orbit data, before calling any point new.
  • Measure brightness and noise per band, and use the error estimates to set a detection threshold that controls false positives.
